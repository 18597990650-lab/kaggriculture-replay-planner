# 资产与平台说明

仓库中的 Python 源码、配置、文档、研究脚本和测试用于展示方案结构与复现离线检查。比赛运行包还包含针对 Linux x86_64 + CPython 3.11 构建的压缩模型和本地扩展；可审阅的二进制与压缩模型按目录保存在 `agent/` 中。

完整比赛运行包 `submission.tar.gz` 作为 [v1.0.0 Release](../../releases/tag/v1.0.0) 的附件提供，并记录了 SHA-256 摘要。

在 Windows 上可以阅读源码、运行结构检查和发布校验；要直接执行完整运行代理，应使用目标平台和对应 Python 版本。线上提交、完整对局评估和排行榜结果不由本仓库的离线检查自动推断。
